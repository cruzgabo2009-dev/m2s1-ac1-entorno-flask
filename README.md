# Entorno En Flask
Para poder empezar no desde cero para hacer una pagina web, para algun negocio, campaña publicitaria o por simple divercion
## Requisitos
- Python 3.12 o superior
- Git
## Instalación
1. Clona este repositorio: `git clone https://github.com/cruzgabo2009-dev/m2s1-ac1-entorno-flask.git`
2. Entra a la carpeta del proyecto: `cd [nombre de la carpeta]`
3. Crea el entorno virtual: `python -m venv .venv`
4. Actívalo: en Windows `.venv\Scripts\activate`; en macOS/Linux `source
.venv/bin/activate`
5. Instala las dependencias: `pip install -r requirements.txt`
6. Crea tu archivo de configuración a partir del ejemplo: en Windows
`copy .env.example .env`; en macOS/Linux `cp .env.example .env`
## Ejecución
`python app.py`
Abre tu navegador en http://127.0.0.1:5000
